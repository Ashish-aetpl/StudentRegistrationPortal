# Special Campaign 2026 - Master Full Stack React Application

A complete, production-ready Full Stack project equipped with a Sticky Glass Navigation Bar, Smooth Section Scrolling, English UI, and Secure Admin Console.

---

##  Key Updates & Additions

1. **Sticky Glass Navbar (`Navbar.jsx`)**:
   - Navigation links with smooth scroll:
     - **Overview** (`#home`)
     - **Registration Form** (`#registration`)
     - **Photo Gallery** (`#gallery`)
     - **Admin Portal** (`#admin`)
     - **Register Now** quick CTA button
2. **100% Professional English Interface**:
   - Zero mixed language; all titles, notifications, validation errors, and buttons are in standard corporate English.
3. **Pre-configured `.env` File**:
   - Located at `frontend/.env` with `VITE_API_BASE_URL=http://localhost:5000`.
4. **Enhanced Design System**:
   - Polished dark radial backdrop with glassmorphic cards, custom check selections for **Poster Making** & **Elocution**, and security alphanumeric captcha.
5. **Admin Portal**:
   - Password: `admin@special2026`

---

##  Quick Run Instructions

### 1. Start Backend API Server
```bash
cd special-campaign-master/backend
npm install
npm start
```

### 2. Start Frontend App
```bash
cd special-campaign-master/frontend
npm install
npm run dev
```

###  Instant 1-Click Preview
Open `frontend/preview-direct-run.html` directly in any web browser without running terminal commands.
